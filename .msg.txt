feat(nav): make the watchlist and benchmarks pages reachable, fix FR watchlist copy

The previous two commits shipped /watchlist and /benchmarks with no navigation to
either. A page nobody can find is not a feature, so this closes the loop.

Nav links
- "My parts" and "Benchmarks" added to the desktop bar AND the mobile drawer,
  each with correct aria-current so the active section is still announced.
- Locale-aware automatically: they render /watchlist on the English routes and
  /fr/watchlist on the French ones, because the shared chrome resolves its
  locale from data-locale. Verified in a browser on /fr: both links resolve to
  the /fr/ paths after hydration.

WatchNavCount badge
Shows the number of tracked parts next to "My parts", and renders nothing at all
when that number is zero, so the nav is unchanged for people who have not used
the feature.

Deliberately shows the COUNT, not the number that dropped. The drop count needs
live prices, and fetching /api/watchlist on every page load to render one digit
in a nav bar is a bad trade - a round trip on every navigation for a number most
people will not look at. The detail belongs on the page you land on, which is
exactly where the watchlist puts it.

French copy, actually fixed
While verifying the FR nav I found the entire watchlist interface rendering in
English on the French site. Eight keys had been written with the English string
in fr.ts:

  watch.title, watch.nav, watch.browse, watch.lowest, watch.trend,
  watch.added, watch.noOffers, watch.summary

All eight replaced with real French, and the fix was verified by diffing every
watch.* value against its English twin rather than by eye. "My parts" is now
"Mes pieces" with the accent intact.

That class of error is easy to reintroduce: the fr.ts file is the shape source
and nothing fails to compile when a value is simply copied. Worth a check in
review.

Verified: tsc clean, next build passes, nav links resolve correctly in both
locales after hydration, and the French dictionary no longer shares any watch.*
value with the English one.
